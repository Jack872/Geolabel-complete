# 实现计划：模型辅助标注功能

## 概述

本实现计划将模型辅助标注功能集成到现有标注系统中。核心策略是最小化改动，复用现有的推理代码（inference.py）和标注渲染逻辑（generateMarkLayer、refreshMarkGeoJsonArr）。前端仅在现有模型辅助工具区域增加模型选择下拉框和生成按钮，后端复用现有的 reqInferenceFunction API。
