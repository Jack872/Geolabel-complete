# 溯源管理界面优化 - 安装指南

## 修复的主要问题

### ❌ 原问题：前端只显示任务实体
**现象**: 溯源界面只能显示TASK类型的实体，其他实体类型（RAW_IMAGE、SAMPLE_SET、ANNOTATION_REVISION等）无法正常显示

### ✅ 解决方案：完整PROV实体支持
**修复内容**:
1. **分析Java后端PROV数据结构** - 发现后端支持完整的PROV模型
2. **更新前端实体类型映射** - 支持所有后端实体类型
3. **添加活动类型翻译** - 支持UPLOAD、ANNOTATE、AUDIT_PASS等实际活动
4. **集成代理信息显示** - 显示执行活动的用户或系统信息
5. **优化数据处理逻辑** - 正确处理activities、entities、relations、agents四个数据集合

## 安装步骤

### 1. 安装新增依赖

在前端项目根目录下运行：

```bash
cd Frontend(React)/portal
npm install @antv/g6@^4.8.24
```

### 2. 重启开发服务器

```bash
npm run start:dev
```

## 修复后的功能特性

### ✅ 支持的实体类型（完整列表）

#### 后端实际实体类型
- `TASK` → 标注任务
- `RAW_IMAGE` → 原始影像  
- `SAMPLE_SET` → 样本集
- `ANNOTATION_REVISION` → 标注版本
- `AUDIT_REJECT` → 审核记录

#### 扩展实体类型
- `DATASET` → 数据集
- `MODEL` → 模型文件
- `ANNOTATION` → 标注数据
- `IMAGE` → 图像文件
- `LABEL` → 标签文件
- `CONFIG` → 配置文件
- `LOG` → 日志文件
- `RESULT` → 结果文件

### ✅ 支持的活动类型（完整列表）

#### 后端实际活动类型
- `UPLOAD` → 文件上传
- `ANNOTATE` → 数据标注
- `AUDIT_PASS` → 审核通过
- `AUDIT_REJECT` → 审核驳回
- `DATASET_GENERATE` → 数据集生成
- `DATASET_EXPORT` → 数据集导出
- `PUBLISH_SERVICE` → 发布服务

### ✅ 支持的代理类型
- `PERSON` → 👤 用户（如：张三、李四）
- `SOFTWARE` → 🤖 软件系统（如：数据处理系统）
- `ORGANIZATION` → 🏢 组织机构
