# 溯源管理界面优化说明

## 修复的主要问题

### 🔧 实体类型支持不完整
**问题**: 前端只显示任务实体，无法显示其他PROV实体类型
**解决**: 
- 分析Java后端完整的PROV数据结构
- 添加对所有实体类型的支持：RAW_IMAGE、SAMPLE_SET、ANNOTATION_REVISION、AUDIT_REJECT等
- 更新实体类型映射和翻译

### 🔧 活动类型翻译不完整  
**问题**: 缺少后端实际使用的活动类型翻译
**解决**:
- 添加UPLOAD、ANNOTATE、AUDIT_PASS、AUDIT_REJECT等后端实际活动类型
- 提供完整的中文翻译和图标映射

### 🔧 代理信息缺失
**问题**: 前端未显示执行活动的代理（Agent）信息
**解决**:
- 在关系图谱中显示代理名称和类型
- 在详情面板中展示完整的代理信息
- 支持PERSON、SOFTWARE、ORGANIZATION三种代理类型

### 🔧 数据结构不匹配
**问题**: 前端数据处理逻辑与后端API返回结构不完全匹配
**解决**:
- 更新数据处理逻辑以支持完整的PROV数据结构
- 正确处理activities、entities、relations、agents四个数据集合
- 添加关系映射和实体关联逻辑

## 支持的实体类型（完整列表）

### 后端实际实体类型
- `TASK` → 标注任务
- `RAW_IMAGE` → 原始影像
- `SAMPLE_SET` → 样本集
- `ANNOTATION_REVISION` → 标注版本
- `AUDIT_REJECT` → 审核记录

### 扩展实体类型
- `DATASET` → 数据集
- `MODEL` → 模型文件
- `ANNOTATION` → 标注数据
- `IMAGE` → 图像文件
- `LABEL` → 标签文件
- `CONFIG` → 配置文件
- `LOG` → 日志文件
- `RESULT` → 结果文件

## 支持的活动类型（完整列表）

### 后端实际活动类型
- `UPLOAD` → 文件上传
- `ANNOTATE` → 数据标注
- `AUDIT_PASS` → 审核通过
- `AUDIT_REJECT` → 审核驳回
- `DATASET_GENERATE` → 数据集生成
- `DATASET_EXPORT` → 数据集导出
- `PUBLISH_SERVICE` → 发布服务

### 扩展活动类型
- `DATASET_IMPORT` → 数据集导入  
- `DATASET_CREATE` → 数据集创建
- `DATASET_UPDATE` → 数据集更新
- `DATASET_DELETE` → 数据集删除
- `MODEL_TRAIN` → 模型训练
- `MODEL_INFERENCE` → 模型推理
- `DATA_VALIDATION` → 数据验证
- `QUALITY_CHECK` → 质量检查
- `AUDIT_LOG` → 审计记录

## 支持的代理类型

- `PERSON` → 👤 用户（如：张三、李四）
- `SOFTWARE` → 🤖 软件系统（如：数据处理系统）
- `ORGANIZATION` → 🏢 组织机构

## 使用说明

1. **安装依赖**:
   ```bash
   cd Frontend(React)/portal
   npm install @antv/g6@^4.8.24
   ```

2. **启动项目**:
   ```bash
   npm run start:dev
   ```

3. **访问溯源管理页面**，选择数据集查看溯源信息

4. **交互操作**:
   - 点击左侧数据集列表选择要查看的数据集
   - 在关系图谱或时间轴中点击节点查看详细信息
   - 使用图谱工具进行缩放、拖拽等操作
   - 支持导入离线溯源文件
